# TJ Manufaktur – GitHub Pages

Diese Version ist direkt für GitHub Pages vorbereitet.

## Veröffentlichung
1. Öffne im Repository **Settings → Pages**.
2. Unter **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
3. Speichern.
4. Danach ist die Website unter `https://TJ-Manufaktur.github.io/tj-manufaktur/` erreichbar.

## Vor der Veröffentlichung anpassen
- In `kontakt.html` E-Mail und Telefonnummer ersetzen.
- In `script.js` `DEINE-EMAIL@BEISPIEL.DE` ersetzen.
- Impressum, AGB und Datenschutz final anpassen.
- Eigene Produktbilder in `assets/` ablegen und die Bildpfade in `index.html` ersetzen.

## Google Sites
Die veröffentlichte URL kannst du in Google Sites über **Einfügen → Einbetten → URL** einbinden.
